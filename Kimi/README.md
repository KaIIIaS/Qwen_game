# Chicken Invaders — Galactic Campaign

Апгрейд проекта: полноценное меню, режим кампании, переработанные волны,
пять уникальных боссов с собственными текстурами и кучей мелких улучшений.

## Запуск

```bash
pip install pygame numpy
cd Kimi
python main.py
```

`numpy` не обязателен — без него просто отключится звук (он синтезируется на лету,
никаких wav-файлов в репозитории не нужно).

## Как поставить поверх старой версии

1. Скопируйте все `.py` из этого архива в папку `Kimi/`, заменив старые.
2. Скопируйте 5 файлов `boss_*.png` в `Kimi/assets/` — **старые текстуры не трогайте**,
   они все используются.
3. Удалите `Kimi/__pycache__/` (там лежат скомпилированные старые модули).

## Что нового

### Меню
* Главный экран: **Кампания / Бесконечный режим / Настройки / Выход**.
* Экран выбора сектора: карточки уровней, замки, звёзды, рекорды, имя босса.
* Настройки: сложность (4 уровня), управление (мышь/клавиатура), полный экран,
  громкость, тряска экрана, качество частиц, счётчик FPS. Всё сохраняется в
  `savegame.json` рядом с игрой.
* Экран справки с описанием механик.

### Кампания
5 секторов, у каждого свой цвет фона, брифинг, набор волн и финальный босс:

| Сектор | Название | Босс |
|---|---|---|
| I | Курятник | Генерал Клак |
| II | Инкубатор | Мать-Наседка |
| III | Верфь | Хром-Растер MK-III |
| IV | Ледник | Ледяная Наседка |
| V | Ядро | Омега-Клюв (4 фазы) |

Звёзды: 3 — прошёл без потерь, 2 — не больше двух потерь, 1 — просто прошёл.
Следующий сектор открывается после прохождения предыдущего.

### Волны
Раньше волна была одна и та же: N кур падают сверху синусоидой.
Теперь волна — это набор **отрядов**, у каждого своё построение, поведение,
тип врага и задержка появления.

* **8 типов врагов**: normal, scout, heavy, shooter, gunner, kamikaze, shielded, tank.
  У стрелков разные паттерны огня, у щитовиков — щит поверх HP.
* **7 моделей поведения**: dive, hold (строй с зависанием), kamikaze (наводится
  на игрока с телеграфом), strafe, orbit, swoop, zigzag.
* **10 построений**: line, grid, vee, arc, column, sides, pincer, circle, scatter, wall.
* В бесконечном режиме волны генерируются процедурно с модификаторами
  (РОЙ, ЭЛИТА, КАМИКАДЗЕ, ОСАДА) и растущей сложностью; босс — каждая 5-я волна.

### Боссы
У каждого 3 фазы (у финального — 4), 5–7 уникальных атак, полоса HP с делением
на фазы, вспышка и залп при смене фазы, эффектная сцена гибели.
Атаки описаны генераторами, так что многошаговые паттерны читаются линейно.

Новые опасности: **лучи** (сначала мигают, потом жгут), **ледяные поля**
(замедляют корабль), **яйца-мины** (вылупляются во врагов), **сингулярность**
(притягивает игрока).

### Игрок
* **Бомба** (ПРОБЕЛ): сносит все вражеские снаряды и бьёт по всем врагам.
* **Точный режим** (SHIFT): медленное движение для протискивания между пулями.
* **Щит**, **магнит** (бонусы летят сами), новые дропы.
* Смерть теперь снимает один уровень оружия — это цена, а не просто минус жизнь.
* Самонаведение у ракет, пробитие у лазеров и льда.

### Прочее
* Фон: параллакс-звёзды, туманности в цвет сектора, метеоры.
* Кэш шрифтов и свечений — заметно меньше нагрузка на CPU.
* Пути к `assets` больше не зависят от рабочей директории.
* Разрешение экрана определяется корректно (старый трюк с `global SCREEN_WIDTH`
  на самом деле не работал).
* Процедурный звук: выстрелы, взрывы, бонусы, предупреждения.

## Управление

| Клавиша | Действие |
|---|---|
| Мышь / WASD / стрелки | движение |
| — | огонь автоматический |
| SHIFT | точный режим |
| ПРОБЕЛ | бомба |
| ESC | пауза / назад |
| F1 | счётчик FPS |
